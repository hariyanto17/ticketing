# Cashier Installation Guide

> Use this short guide only after IT has provided an approved signed installer and confirmed the Windows printer driver.

## Install

1. Connect and power on the Epson TM-T82/TM-T82III.
2. Install the Epson Windows printer driver if IT has not already done so.
3. Confirm Windows can print a test page.
4. Run `Planet Cinema Printer Agent Setup.exe`.
5. Complete the installer and allow the desktop/Start Menu shortcut.
6. Confirm the Planet Cinema Printer Agent tray icon appears.
7. Open the Cinema web application.
8. Go to **Settings > Printer Setup**.
9. Confirm the agent shows **Connected**.
10. Select the Epson printer shown in the list.
11. Select the paper width that matches the roll.
12. Turn **Auto Cut** on if the printer has a cutter.
13. Click **Save**.
14. Click **Test Print**.
15. Confirm the physical ticket is readable, the QR scans, and the cutter behaves as expected.

## If it does not work

- If the agent says **Not Connected**, confirm the tray agent is running and contact IT.
- If no Epson printer appears, confirm the Windows driver and Windows test page, then contact IT.
- If the ticket prints incorrectly, keep the ticket and record the time and printer name.
- Do not disable Windows Defender, SmartScreen, or antivirus.
- Do not change printer driver settings unless instructed by IT.
